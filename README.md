# DormMate 宿舍环境分析工具

一个原生前端（无框架）的宿舍温湿度环境分析工具，支持数据录入、CSV 导出、趋势图报告，以及摄像头、语音识别（ASR）、语音合成（TTS）本机交互。

## 运行方式

### 方式一：基础功能（直接打开）

双击 `index.html` 用浏览器打开即可，可使用以下功能：

- 环境分析、CSV 导出、报告视图

> 摄像头、语音识别等功能依赖浏览器「安全上下文」，`file://` 直接打开时可能不可用，请使用方式二。

### 方式二：完整功能（通过 localhost 访问）

在项目目录下启动一个本地 HTTP 服务：

```bash
python -m http.server 8000
```

然后用 Chrome / Edge 访问 <http://localhost:8000>，即可使用全部功能（含摄像头、语音识别）。

> 摄像头要求页面运行在 `localhost` 或 `https://` 下，这是浏览器 `getUserMedia` 的安全策略。

### 数据分析脚本（可选）

网页导出 `dormmate.csv` 后，可用 Python 脚本生成统计报告与趋势图：

```bash
python analyze.py
```

运行后生成 `trend.png`（趋势图）和 `report.html`（报告），需安装依赖：

```bash
pip install matplotlib
```

## 主要功能

- **环境分析**：录入温湿度，按多分支规则判断宿舍环境状态（偏热 / 偏冷 / 潮湿 / 干燥 / 正常），并给出建议。
- **历史记录**：分析结果累加到历史列表（内存存储，刷新清空）。
- **导出 CSV**：把历史记录导出为 `dormmate.csv`（含 time、temperature、humidity、status 四列，UTF-8 编码）。
- **报告视图**：导出后切换到报告页，展示统计摘要、温湿度双折线趋势图（Canvas 绘制）、异常记录表格。
- **数据分析（Python）**：`analyze.py` 读取 CSV，做统计、判断状态、绘制趋势图、生成 HTML 报告。
- **摄像头**：开启摄像头预览，并截取单张现场快照。
- **语音识别（ASR）**：识别中文语音，支持固定指令：
  - 「朗读状态」→ 触发语音合成朗读当前环境状态
  - 「拍照」→ 触发现场快照
- **语音合成（TTS）**：朗读当前环境状态，内容随最新分析结果动态变化。

## 已知限制

- **摄像头需安全上下文**：`getUserMedia` 要求页面运行在 `localhost` 或 HTTPS 下，`file://` 直接打开时摄像头可能无法使用。
- **语音识别兼容性**：`SpeechRecognition`（Web Speech API）目前主要被 Chrome、Edge 支持，Firefox、Safari 不支持。不支持的浏览器中页面会降级为手动输入指令（保留文字展示区与指令触发逻辑）。另外，Chrome 的语音识别依赖网络服务，离线时无法识别。
- **语音合成依赖系统语音包**：`speechSynthesis` 的朗读效果取决于操作系统是否安装中文语音。
- **麦克风 / 摄像头权限**：首次使用需在浏览器弹窗中允许授权，拒绝后需在浏览器设置里重新开启。
- **历史记录仅内存存储**：刷新页面后历史清空，不会持久化到本地。
- **数据分析需 Python 环境**：`analyze.py` 依赖 Python 3 与 matplotlib，中文字体需系统安装「微软雅黑」或「黑体」，否则趋势图中文可能显示为方框。
